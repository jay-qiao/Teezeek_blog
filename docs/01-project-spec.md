# 项目规范

## 1. 项目定位

Teezeek 的个人展示博客，以原创"烬土"暗黑奇幻世界观为包装，本质仍是常规的个人博客：文章、标签、搜索、目录、代码高亮、RSS、关于页等常用功能齐全，不因奇幻主题牺牲可用性。

## 2. 技术栈

| 项目 | 选择 |
| --- | --- |
| 静态站点 | VitePress 1.6.4 |
| 前端框架 | Vue 3（Composition API） |
| 模块规范 | ES Module |
| 包管理器 | npm |
| 部署平台 | GitHub Pages（项目页） |
| 仓库 | `jay-qiao/Teezeek_blog` |
| 线上地址 | `https://jay-qiao.github.io/Teezeek_blog/` |

## 3. 内容模型

所有内容以 Markdown 文件存放于 `site/`，正文位于 `site/posts/`，公告位于 `site/updates/`。

文章 frontmatter 固定字段：

```yaml
---
title: 文章标题
description: 一句话摘要
date: 2026-08-10
tags:
  - VitePress
---
```

## 4. 页面地图

| 路由 | 叙事名称 | 用途 |
| --- | --- | --- |
| `/` | 烬土大厅 | 信卷入口 + 导航地图 |
| `/posts/` | 文章站台 | 文章列表与标签筛选 |
| `/updates/` | 公告栏 | 站点动态与公告 |
| `/tools/` | 工具屋 | 工具集合 |
| `/leaderboard` | 屠龙勇士榜 | 用户贡献排行（默认演示数据） |
| `/about` | 议事厅 | 关于我 |
| `/admin/*` | 管理员后台 | GitHub API 后台，不接服务器后端 |
| `/404` | 迷雾森林 | 404 页面 |

## 5. 常用功能清单

- 文章列表、标签筛选、文章详情
- 文章分类筛选
- 本地全文搜索
- 文章目录（TOC）、上一篇 / 下一篇
- Shiki 代码高亮
- RSS / sitemap / robots.txt 自动生成
- 响应式布局、减少动态效果偏好支持
- 每次新会话显示信卷，点击后播放约 1.5 秒龙文加载动画并覆盖页面、显示大号进度条，再进入地图
- 暗金倾斜雨丝、灰烬粒子、鼠标光晕
- 路由切换轻微渐隐渐现，不打断阅读
- 非首页 / 非管理后台显示左上角返回箭头，回到上一页或首页
- 屠龙勇士榜
- GitHub API 后台：仪表盘、文章管理、分类标签、图片上传、投稿审核、Utterances 评论、屠龙榜管理、协作者管理、系统设置、外观设置、数据备份
- 访客投稿：投稿以 GitHub Issue 进入审核队列，管理员通过后才发布为文章
- 屠龙榜自动计分：文章 100 分 / 评论 10 分，只有管理员批准的用户才会展示在榜单
- 404 页面

## 6. 质量门禁

- `npm ci` 后能通过 `npm run docs:build`
- 本地 `docs:dev` 无控制台错误
- 每次新增页面必须补充对应导航或地图入口
- 新文章必须包含 title、date、tags、description
- 新文章默认补充 category 分类字段
- 样式优先使用设计令牌变量，不散落魔法数字
