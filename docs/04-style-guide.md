# 网站风格规范

## 1. 世界观

站点以"龙族 / 卡塞尔学院"为设定：古堡、羊皮纸、火漆、龙文符号、暗金与龙血。叙事名称只作为 UI 包装，底层路由保持普通博客结构。

## 2. 色彩令牌

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--r-bg` | `#0A0A0A` | 页面主背景 |
| `--r-bg-deep` | `#07070B` | 深一层的背景 |
| `--r-purple` | `#1A0A2E` | 深空紫，毛玻璃与区块底色 |
| `--r-gold` | `#C9A84C` | 暗金，主强调、标题、链接 |
| `--r-gold-bright` | `#E2C56A` | 亮金，悬停与发光 |
| `--r-crimson` | `#8B0000` | 龙血红，火漆与重要标记 |
| `--r-blood` | `#C2453D` | 血焰红，暗底可读的次级强调 |
| `--r-parchment` | `#F5E6C8` | 羊皮纸白，正文 |
| `--r-silver` | `#B8B8B8` | 银灰，次要文字 |
| `--r-ash` | `#6E6A78` | 灰烬灰，弱化信息 |

## 3. 字体层级

- 拉丁展示标题：Cormorant Garamond 700 Italic。
- 中文标题：Noto Serif SC 700 / 900。
- 正文：Noto Serif SC 400，行高 1.8。
- 代码：JetBrains Mono 400 / 600。

## 4. 首页入口

- 每次新会话：直接出现羊皮纸信卷 + 火漆封印。
- 点击"确定进入"后火漆碎裂、信卷展开，随后进入约 1.5 秒全屏龙文加载动画。
- 加载阶段以厚重黑幕覆盖页面，进度条加粗并显示百分比。
- 加载完成后进入卡塞尔大厅羊皮卷地图。
- 状态写入 sessionStorage，同一会话内不再重复展示信封。

## 5. 羊皮卷地图

- 五个入口作为地标分布在羊皮纸卷面上，不做规整卡片网格。
- 地标之间用虚线路径连接，配合罗盘、龙文刻痕与缝线边框。
- 移动端切换为纵向羊皮列表，保持可点性与可读性。

## 6. 氛围层

- 全局背景使用屠龙战场废墟图并轻度压暗，保留战场细节，让雨幕落在战场之上。
- 全局灰烬粒子由 Canvas 绘制，粒子数限制在 40 以内。
- 暗金倾斜雨丝与少量灰烬粒子倾斜下落，以暗金为主、墨绿点缀，并使用 screen 混合融入背景。
- 鼠标移动带有暗金光晕拖尾。
- 路由切换采用轻微渐隐渐现，避免弹层和字幕打断阅读。
- 非首页 / 非管理后台显示左上角返回箭头，优先返回上一页，无历史记录时回大厅。
- 深色背景叠加深空紫光晕，避免大面积纯黑。
- 卡片使用毛玻璃 + 细金边，圆角不超过 8px。
- 交互反馈以发光、边框变色为主，不做夸张位移。

## 7. 排版原则

- 文章正文最大宽度约 760px，保证中文长文阅读舒适。
- 标题、标签、按钮使用暗金；正文保持羊皮纸白。
- 代码块使用深底 + 金色关键字高亮，注释使用银灰。
- 首页地图在移动端改为纵向卡片流，保持可点性。
- 管理员后台采用独立布局，桌面端侧边栏、移动端汉堡菜单收起。
