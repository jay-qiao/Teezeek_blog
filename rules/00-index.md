## 强制要求：README 同步

- 任何网站功能、后台模块、页面结构或部署方式的改动，都必须同步更新 `README.md`。
- README 是面向访客与协作者的项目说明书，内容必须与线上站点一致。
- 提交前检查 README 中的功能清单、技术栈、目录结构、文档入口、自动部署说明是否仍然准确。
- 新增页面、新增后台模块、更换评论/部署/投稿方案时，README 必须同时更新，否则不允许提交。
