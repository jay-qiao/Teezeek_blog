# 写作规范

## 内容要求

- 文章使用中文撰写，代码、专有名词、链接保留原文。
- 每篇文章必须有 title、description、date、tags。
- 文章建议补充 category 分类字段，与已有分类保持一致。
- description 控制在 80 字以内，用于列表与 RSS 摘要。
- 标签控制在 3 到 5 个，使用已有标签，不随意发明同义标签。

## 文件要求

- 文件名使用英文短横线命名，如 `vitepress-deploy.md`。
- 正文文件放在 `site/posts/`，公告放在 `site/updates/`。
- 图片放入 `site/public/images/`，引用绝对路径。

## 格式要求

- 使用 Markdown 标准语法，优先使用 VitePress 扩展语法。
- 代码块必须标注语言。
- 长文使用二级、三级标题分层，让目录可用。
- 不使用 emoji 作为正文装饰，主题装饰符号除外。
